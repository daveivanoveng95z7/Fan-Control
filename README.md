# Fan-Control – Cooling Management Software for Windows

Fan-Control is a fan control and cooling management application for Windows. It provides real‑time temperature monitoring, manual and automatic fan speed adjustment, custom fan curves, and multiple cooling profiles.

## 🔑 Key Features

- Real‑time temperature monitoring (CPU, GPU, motherboard, drives, etc.)
- Manual and automatic fan speed control (PWM and DC voltage)
- Custom fan curves with an intuitive editor
- Multiple cooling profiles (silent, performance, gaming)
- Profile switching automation based on load or temperature
- Support for ITE, Nuvoton, Fintek and other monitoring chips (SMBus, WMI, onboard)
- Customizable interface (themes, graphs, widgets)
- New in V273: stability improvements, faster UI, expanded sensor database, new presets, bug fixes

## 📥 Installation Guide

1. **[Download]()** the ZIP archive of **Fan-Control V273**.
2. **Extract** the contents to any folder (use 7‑Zip, WinRAR, or Windows built‑in extractor).
3. **Right‑click** `Setup.exe` and select **“Run as administrator”**.
4. Follow the on‑screen prompts to complete the setup.

> ⚠️ Administrator rights are required for low‑level sensor driver access and registry registration.

## 💻 System Requirements (Recommended)

| Component | Minimum |
|-----------|---------|
| OS        | Windows 10 64‑bit (or 11) |
| Processor | Multi‑core (Intel Core i3 / AMD Ryzen 3 or better) |
| RAM       | 4 GB (8 GB for heavy logging) |
| Storage   | 2 GB free space (plus extra for logs) |
| Sensors   | SMBus, WMI, or onboard motherboard controller support |
